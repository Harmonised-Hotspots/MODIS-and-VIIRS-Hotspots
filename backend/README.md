# Setup

1. Install the [DuckDB CLI](https://duckdb.org/docs/2.0/installation?platform=windows&environment=cli) and ensure it's available in your PATH
2. Run `./scripts/import-data.sh` to download and import data
3. Install uv (https://docs.astral.sh/uv/#installation)
4. Run `uv sync` to install dependencies
5. Run `./scripts/start-backend.sh` to start the backend server
